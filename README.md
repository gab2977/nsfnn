# ♿ Acessibilidade na Escola

## Sobre o projeto
Este projeto consiste em uma página web desenvolvida com o objetivo de apresentar orientações sobre como construir um ambiente escolar mais inclusivo e acessível. A estrutura utiliza cards simples para dividir conceitos fundamentais como comunicação, ambiente, linguagem e rotina, facilitando a assimilação do conteúdo.

---

## Tecnologias
- **HTML5**
- **CSS3**
- **GitHub**
- **GitHub Pages**

---

## Práticas de acessibilidade utilizadas
1. **Estrutura HTML organizada:** Uso de marcas semânticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
2. **Contraste adequado:** Cores de texto escuras sobre fundo claro para garantir ótima visibilidade.
3. **Fonte legível e espaçamento:** Tipografia sem serifa (Arial) com tamanho ampliado (18px) e espaçamentos consistentes.
4. **Layout previsível e responsivo:** Grid que se adapta a telas de computadores e celulares de forma organizada.
5. **Acessibilidade por teclado:** Indicação visual evidente do foco (`:focus-visible`) para quem navega utilizando a tecla Tab.

---

## Refletindo sobre o projeto

### Qual foi a principal preocupação que você teve ao criar uma página acessível?

A minha principal preocupação ao criar esta página foi garantir a simplicidade e a clareza da informação, evitando a sobrecarga cognitiva nos usuários. Busquei selecionar uma paleta de cores neutra e sóbria para não gerar distrações visuais desnecessárias, focando no alto contraste do texto para facilitar a leitura. Além disso, estruturei o conteúdo com cartões padronizados e uma navegação previsível, garantindo que qualquer pessoa, independentemente de suas habilidades ou do dispositivo utilizado (computador ou celular), consiga absorver o conhecimento de forma rápida, confortável e autônoma.
